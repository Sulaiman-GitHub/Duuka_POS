# Demo video script (about 3 minutes)

An optional walkthrough for the submission. Screen-record the live site on a laptop; narrate in plain language.

| Time | Screen | Say |
|---|---|---|
| 0:00 | Sign-in page | "This is Duuka POS, a web-based point-of-sale and inventory system, running live online. It has three roles: administrator, manager and cashier." |
| 0:15 | Sign in as **cashier** → POS | "The cashier gets a fast till. I can search or scan a barcode, tap products, change quantities, and apply a discount — cashiers are limited to 10%, and that limit is enforced on the server." |
| 0:45 | Add items, pick **Mobile Money**, **Complete sale** | "Four payment methods. Totals are always recalculated on the server, so the screen can't change what's charged." |
| 1:05 | Receipt → **Print** | "A numbered receipt, ready to print. Stock was reduced automatically." |
| 1:15 | Try **Hold** on another sale | "Parked sales let me serve the next customer and come back." |
| 1:30 | Sign in as **manager** → **Sales** → open a receipt → **Return / refund** | "Managers can see every sale and process returns. The refund respects the discount that was given, and the items go back into stock." |
| 1:55 | **Inventory** → **Stock history** | "Every stock change is recorded — who, when, why — and stock can never go negative, even if two tills sell the last item at once." |
| 2:10 | **Dashboard** | "Today's sales, profit, best sellers, payment mix, and what needs restocking." |
| 2:25 | **Reports** → **Export CSV** / **Save as PDF** | "Seven reports with date filters, daily, weekly or monthly, exportable to CSV or PDF." |
| 2:40 | **Suppliers & Orders** → receive part of an order | "Bonus: purchase orders, with partial deliveries that update stock." |
| 2:50 | Sign in as **admin** → **Users**, **Activity log** | "Admins manage staff and can see an audit trail of everything that happened." |
| 3:00 | README / GitHub | "Source code, database schema, tests and documentation are all in the repository. Thank you." |

Tips: use the stable address `https://pos-tawny-psi.vercel.app`; start from a freshly reset demo database so the numbers look clean.
